# Vibe Data Universe 系统使用手册

本手册面向首次使用者，覆盖安装启动、数据接入、清洗、分析、3D 数据宇宙、故事编排、报告导出以及常见问题。

## 1. 系统概览

Vibe Data Universe 是一个本地优先的数据探索应用。你可以直接导入文件，在同一个界面中完成：

1. 自动识别字段类型并检查数据质量。
2. 生成不会覆盖原始数据的清洗版本。
3. 运行探索性分析、智能图表推荐和高级统计。
4. 用 3D 粒子观察数据分布并向数据提问。
5. 将结果组织成数据故事并导出 HTML 或 PDF。

系统默认不需要账户或外部服务。只要前后端正常启动，本地统计引擎即可完成核心分析。

## 2. 安装与启动

### 2.1 环境要求

- Python 3.13
- Node.js 24
- `uv`

建议先检查版本：

```powershell
python --version
node --version
uv --version
```

### 2.2 启动后端

```powershell
cd backend
uv sync --extra dev
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

启动成功后可访问：

- 健康检查：`http://127.0.0.1:8000/api/health`
- API 文档：`http://127.0.0.1:8000/docs`

### 2.3 启动前端

另开一个终端：

```powershell
cd frontend
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。

### 2.4 Docker 启动

如果已安装 Docker Desktop，可以在项目根目录执行：

```powershell
docker compose up --build
```

Web 应用仍位于 `http://127.0.0.1:5173`，API 文档位于 `http://127.0.0.1:8000/docs`。

## 3. 首次进入

当系统中没有数据集时，首页会自动创建一份“校园学习节律”演示数据。它包含日期、院系、活动、学习时长、睡眠时长、课程成绩、月度支出和满意度等字段，适合体验所有主要功能。

也可以手动导入仓库中的示例文件：

```text
examples/student_learning_rhythm.csv
```

页面顶部的“当前数据”下拉框决定所有工作区正在使用的数据集。切换后，数据宇宙、数据工作台、分析实验室和故事编辑器会同步到新的数据集。

## 4. 数据工作台

![数据工作台](screenshots/data-workbench.png)

### 4.1 接入文件

进入左侧导航的“数据工作台”，点击“接入文件”，选择本地文件。支持：

- CSV
- Excel：`.xlsx`、`.xls`
- JSON
- TXT

默认限制为单文件 128 MiB、最多 50 万行和 300 列。管理员可以通过 `.env` 中的 `UPLOAD_MAX_BYTES`、`DATASET_MAX_ROWS` 和 `DATASET_MAX_COLUMNS` 调整。

### 4.2 查看数据预览

“数据预览”页签展示当前修订的字段和数据行。宽表支持横向滚动，较大的数据集按页从后端读取，不会一次性加载到浏览器。

### 4.3 查看字段画像

“字段画像”页签会为每个字段展示：

- 推断类型：数值、分类、布尔、日期时间或文本。
- 缺失数量和缺失比例。
- 唯一值数量。
- 数值字段的均值、中位数、标准差、四分位数和异常值数量。
- 分类字段的高频取值。
- 日期字段的时间范围。

右侧质量面板汇总缺失单元格、重复行和待关注字段，并给出 0–100 的质量评分。

### 4.4 版本化清洗

“版本化清洗”不会直接修改原始数据，而是创建新的修订版本。可组合：

- 删除重复行。
- 删除包含缺失值的行。
- 按均值、中位数、众数或指定值填充缺失项。
- 使用 IQR 规则标记异常值。

提交前为本次清洗填写清晰的版本名称。完成后可以查看每一步处理前后的行数，并在修订历史中追溯变化。

## 5. 数据宇宙

![数据宇宙](screenshots/data-universe.png)

“数据宇宙”把抽样数据映射为三维粒子：

- 拖动场景旋转视角，滚轮缩放。
- 用底部控制器选择 X、Y、Z 轴和颜色字段。
- 点击暂停或继续自动巡航。
- 点击重置恢复推荐映射。
- 选择粒子查看该行的字段摘要。

右上角的 AI 数据解说员默认使用本地统计证据引擎。输入问题后，系统会基于数据画像、相关性和异常线索生成回答。

## 6. 分析实验室

![分析实验室](screenshots/analysis-lab.png)

### 6.1 智能探索

进入“分析实验室”后，系统自动扫描当前数据集并生成最多四个图表方案。每个方案包含：

- 推荐排名和 0–100 适配分。
- 高、中或探索性置信度。
- 推荐原因和数据证据。
- 自动选择的 X、Y 字段。

系统会在趋势折线图、分组柱状图、关系散点图和分布直方图之间选择最合适的方案。点击左侧候选项即可切换图表；柱状图中的分类还可以点击并联动过滤后续分析。

页面下半部分提供相关性矩阵、最强字段关系和异常样本线索。

### 6.2 与数据对话

“与数据对话”适合用自然语言提出业务问题，例如：

```text
哪些字段之间关系最明显？
数据质量最需要关注什么？
哪个指标存在明显异常值？
```

未配置外部模型时，回答由本地统计证据引擎生成。配置外部模型后，系统会发送聚合后的画像和分析证据来组织更自然的解说，不会发送原始数据行。

### 6.3 高级统计

“高级统计”提供三类分析：

- **线性回归**：选择特征字段和目标字段，返回系数、截距、R² 与 RMSE。
- **Welch 检验**：比较两个群体在某个数值字段上的均值差异，返回统计量和 p 值。
- **KMeans 聚类**：选择多个数值字段和聚类数量，返回轮廓系数与聚类中心。

分析结果会进入右侧历史记录，方便回顾和用于故事编排。

### 6.4 移动端

![移动端分析](screenshots/analysis-lab-mobile.png)

在窄屏设备上，主导航固定在底部，图表推荐列表可横向滚动，图表和证据区域改为单列布局。

## 7. 故事编辑器

![故事编辑器](screenshots/story-studio.png)

### 7.1 创建故事

进入“故事编辑器”，点击“新建故事”。系统会根据当前数据集的质量、相关性和推荐图表生成一个初始故事结构。

### 7.2 编辑故事流

每个故事由多个段落组成，支持开场、关键指标、图表、叙事和数据质量五种类型。你可以：

- 修改故事标题和开场摘要。
- 编辑每一幕的标题与正文。
- 上移、下移或删除段落。
- 添加新的叙事段落。
- 在右侧实时预览阅读效果。

编辑后点击“保存故事”。

### 7.3 导出报告

右侧预览区提供两种导出：

- **HTML**：适合浏览器阅读、分享或继续定制样式。
- **PDF**：适合归档、提交和打印。

导出文件由后端生成并下载到浏览器。生成的报告文件保存在本地运行目录中，不会进入 Git 仓库。

## 8. 协作画布

前端会为当前数据集建立 WebSocket 连接。多个浏览器窗口同时打开同一数据集时，可以同步：

- 在线人数。
- 图表筛选。
- 粒子映射。
- 清洗与故事操作事件。

协作功能不包含账户或权限控制，适合可信的本地或教学网络环境。

## 9. 可选大模型设置

在项目根目录复制环境配置：

```powershell
Copy-Item .env.example .env
```

按需填写：

```text
LLM_API_KEY=...
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-5-mini
LLM_API_STYLE=responses
```

也可以点击 AI 解说员旁的设置按钮，临时选择 OpenAI、DeepSeek、通义千问或兼容服务。界面输入的 API Key 只在当前会话中使用，不会写入数据库、浏览器持久存储或分析历史。

## 10. 本地数据与隐私

默认运行数据位于：

```text
backend/storage/vibe-data.db
backend/storage/datasets/
backend/storage/exports/
```

这些目录和文件已被 `.gitignore` 排除。上传到 GitHub 的是应用源码、文档、示例数据和演示效果图，不包含你本地上传的数据、SQLite 数据库、导出报告或密钥。

## 11. 常见问题

### 前端提示无法连接后端

确认后端正在 `127.0.0.1:8000` 运行，并访问 `http://127.0.0.1:8000/api/health` 检查状态。若修改了端口，请同时设置 `VITE_API_BASE_URL` 和 `BACKEND_CORS_ORIGINS`。

### 修改环境变量后没有生效

停止并重新启动对应进程。Vite 只在启动时读取 `VITE_` 开头的变量，FastAPI 配置也在进程启动时加载。

### Excel 文件无法解析

确认扩展名为 `.xlsx` 或 `.xls`，文件没有加密，并已通过 `uv sync` 安装 `openpyxl` 与 `xlrd`。

### 大文件导入较慢

先减少无关列或拆分文件。系统会拒绝超过环境配置上限的文件，以避免占满本机内存。

### 外部模型连接失败

检查 API Key、Base URL、模型名和 API 风格。OpenAI Responses API 使用 `responses`，兼容 Chat Completions 的服务通常使用 `chat_completions`。
