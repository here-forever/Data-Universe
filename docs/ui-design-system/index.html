◇ 设计理念

顺着用户的心智，而非功能清单

初学者并不把数据分析想成「模块」——他们想的是一条清晰的路：拿到数据、看懂它、收拾干净、问它问题、讲成故事、交出去。我们据此重建界面。

引导式而非菜单式

用工作流回答问题

首次进入即赠送演示数据并开启引导；常驻「工作流进度」让新手始终知道下一步去哪，老手可一键直达任一工作区。

结果要能读懂

用大白话解释统计

每个图表、每项分析都附带「为什么推荐」「证据」「置信度」，把统计术语翻译成用户能行动的结论。

安心比炫技重要

可逆、可重试、可确认

清洗生成新版本而非覆盖；删除前二次确认；请求失败原地重试；异常可全局恢复——降低误操作焦虑。

!

心智模型对齐：把「上传 → 画像 → 清洗 → 分析 → 宇宙 → 故事 → 导出」做成一条贯穿全站的连续旅程，顶部「当前数据集」作为统一上下文，切换后所有工作区自动同步。

◇ 信息架构

以旅程为主线的工作区结构

四大工作区沿数据生命周期排布，顶部「当前数据集」作为统一上下文。新增「新手引导」与「工作流进度」两块引导层，兼顾初学者与熟练用户。

01 · 接入

数据工作台

上传 CSV/Excel/JSON/TXT，查看预览与字段画像，版本化清洗。

02 · 洞察

分析实验室

智能图表推荐、相关性矩阵、自然语言问数、高级统计。

03 · 沉浸

数据宇宙

3D 粒子叙事，映射轴与颜色，巡检粒子，AI 解说。

04 · 表达

故事编辑器

把指标、图表与叙事编排成故事流，导出 HTML / PDF。

⇄

常驻上下文：所有工作区共享同一「当前数据集」。顶栏数据集选择器变更后，宇宙、工作台、实验室、故事同步切换——这是初学者最容易困惑的点，统一后心智负担显著降低。

◇ 导航模型

三层导航，逐级收束注意力

左/底栏负责「去哪个工作区」；工作区内的步骤器负责「我现在在哪一步」；内容区标签负责「这一屏看什么」。三层各司其职，避免一个导航塞下所有信息。

① 全局工作区导航

桌面左侧 208px 轨道（窄屏收为 72px 图标），移动端固定底部 4 项。含品牌、工作流进度入口、协作在线状态。

② 工作流进度器

新手模式顶部显示「接入 → 画像 → 清洗 → 分析 → 叙事 → 导出」进度链，可点击跳转；专家模式可隐藏。

③ 内容区标签 / 面板

工作台内的「预览 / 画像 / 清洗」、实验室内的「探索 / 问数 / 统计」用分段标签切换，降低页面跳转。

◇ 关键交互流程

六条主线，覆盖从第一次打开到交付

每条流程都围绕「降低决策成本」设计：给默认、给解释、给撤销。下面先给出贯穿全站的主工作流，再拆解关键子流程。

主线：数据探索旅程

1

2
画像自动类型与质量评分
3
清洗版本化、可逆
4
分析推荐图表与问数
5
宇宙3D 叙事
6
叙事导出 HTML/PDF

🌱 首次引导

  • 检测无数据集 → 自动创建演示数据
  • 三步高亮导览：数据集、工作区、导出
  • 「跳过引导」常驻，绝不阻塞

📥 导入数据

  • 拖拽落区 + 格式提示（≤128MiB/50万行）
  • 即时进度与失败原因定位
  • 完成后直接跳转画像并给出质量分

🧹 版本化清洗

  • 操作生成新修订，不覆盖原始
  • 每步显示处理前后行数差异
  • 修订历史可回溯、可对比

💬 自然语言问数

  • 本地统计证据引擎先答，零配置可用
  • 答案附「证据来源」与置信度
  • 可选外部模型，仅发聚合画像不發原行

🌌 宇宙探索

  • 一键推荐轴/颜色映射
  • 点击粒子查看该行摘要
  • 低端设备可关后处理，保帧率

📤 故事导出

  • 右侧实时预览阅读效果
  • HTML（可再定制）/ PDF（可归档）
  • 导出失败给重试，不丢已编辑内容

◇ 响应式与无障碍

三断点一致，主题随心切换

移动端主航行固定于底部、内容单列、对话框转为底部抽屉；平板收窄左轨为图标；桌面释放完整三栏。亮/暗主题一键切换并记忆偏好。

断点范围导航布局策略
mobile≤ 760px底部 4 项固定单列；对话框=底部抽屉；图表横向滚动
tablet761–1020px左轨收为 72px 图标浏览器/质量面板转横向；推荐列横向滚动
desktop1021–1280px左轨 208px 全展开完整三栏工作区
large≥ 1281px左轨 + 居中 max 宽放宽间距，提升信息密度舒适度
键盘可达

全功能可 Tab 操作；焦点环统一 2px 主色 + 偏移；对话框 Esc 关闭、焦点陷阱。

屏幕阅读

语义化标签、aria 角色；图表附文本摘要，不靠颜色单独传信息。

减少动效

尊重系统偏好；3D 后处理、自动巡航、粒子力场均可独立关闭。

★

交付建议：本方案建议沿用现有 React + Vite + CSS 变量架构，将上述令牌沉淀为 :root 与 [data-theme]；组件以 CSS Module + 设计令牌实现，确保暗/亮双主题零成本切换。
