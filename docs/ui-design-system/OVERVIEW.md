# Vibe Data Universe · 界面设计方案（Overview）

> 由 UI Designer 基于目标用户心智模型构建的全新界面设计方案。本目录交付一份**自包含、可交互**的设计系统门户。

## 交付物
- **`index.html`** — 交互式设计系统门户（在浏览器直接打开评审）。包含：
  - 设计总览与理念（引导式 / 结果可读 / 安心优先）
  - 视觉令牌系统（Nebula 暗 + Daybreak 亮双主题，WCAG AA）
  - 字体与排版层级
  - 信息架构（四大工作区 + 统一数据集上下文）
  - 三层导航模型（工作区 / 工作流进度 / 内容标签）
  - 四大核心页面**真实 HTML 渲染线框**（含桌面/平板/手机预览切换）
  - 六条关键交互流程拆解
  - 组件规范库（按钮、输入、标签、评分环、对话框、Toast、落区、状态）
  - 响应式断点与无障碍策略

## 设计决策要点
1. **保留品牌「数据宇宙」气质**，但把暗色做得更克制安静，并补齐真正好用的亮色主题（课堂投影 / 长时间阅读）。
2. **对齐初学者线性心智**：把「接入→画像→清洗→分析→宇宙→叙事→导出」做成贯穿全站的连续旅程，顶部「当前数据集」为统一上下文。
3. **可访问性优先**：正文 ≥4.5:1、大字 ≥3:1；主色按钮双主题均满足 AA；质量状态用「颜色+数字/图案」双编码；尊重 `prefers-reduced-motion`，3D 后处理可关。
4. **技术落地建议**：沿用现有 React+Vite+CSS 变量架构，令牌沉淀为 `:root` 与 `[data-theme]`，组件以 CSS Module + 设计令牌实现，暗/亮零成本切换。

## 如何评审
用浏览器打开 `index.html`：右上角可切换明暗主题；各页面线框上方有「桌面/平板/手机」切换；左侧目录随滚动高亮当前章节。
