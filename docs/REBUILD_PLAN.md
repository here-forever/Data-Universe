# Vibe Data Universe 重建计划

本计划以 `instruction.md` 为唯一产品需求来源。目标是让新系统完全替代旧系统，不保留旧产品的信息架构、业务实体、接口兼容层或部署依赖。

## 1. 重建边界

保留并改善：

- FastAPI 与 SQLAlchemy 基础运行能力
- Pandas、NumPy、SciPy、Scikit-learn 数据科学能力
- React、TypeScript、Zustand 与 TanStack Query 工程基础

彻底移除：

- 账户、登录、项目、成员与权限
- 外部数据库连接与 SQL 工作台
- 任务中心、治理、审计、血缘与归档
- 旧数据视图、传统仪表盘和旧报告模型
- PostgreSQL、Redis、worker 与旧演示脚本依赖

## 2. 实施阶段

| 阶段 | 交付物 | 验收条件 | 状态 |
| --- | --- | --- | --- |
| 1. 领域重建 | Dataset、DatasetRevision、AnalysisRun、Story | 新单基线迁移可从空库升级 | 完成 |
| 2. 数据主链 | 四类文件接入、画像、分页、版本化清洗 | 原始修订不被覆盖，限制与错误结构明确 | 完成 |
| 3. 分析引擎 | EDA、图表推荐、联动、问数、回归、检验、聚类 | 结果基于真实修订数据并记录分析历史 | 完成 |
| 4. 体验重建 | 四工作区、3D 粒子、数据色彩、微交互、响应式布局 | 旧路由和旧导航不进入构建产物 | 完成 |
| 5. 叙事协作 | AI 解说、WebSocket、故事编辑、HTML/PDF | 操作可同步，故事可保存与导出 | 完成 |
| 6. 运行验收 | 自动测试、构建、迁移、桌面与移动端 QA | 无阻断错误、重叠、空白画布或旧配置残留 | 完成 |

## 3. 需求映射

| `instruction.md` 要求 | 新系统实现 |
| --- | --- |
| CSV、Excel、JSON、TXT | `POST /api/datasets/upload` |
| 预览、字段类型、基础统计 | 数据工作台与数据画像服务 |
| 去重、缺失值、异常标记 | 版本化清洗步骤 |
| 中文自然语言查询 | 本地统计引擎 + 可选大模型解说 |
| 智能图表与 EDA | 推荐图、分布、相关矩阵、异常检测 |
| 回归、检验、聚类 | 线性回归、Welch t 检验、KMeans |
| 多图表联动 | 分类图点击后带筛选重算全部探索结果 |
| 数据粒子叙事 | R3F/Three.js 3D 粒子场景 |
| 数据故事与报告 | 故事编辑器、HTML/PDF 导出 |
| 协作式分析画布 | 数据集级 WebSocket 事件同步 |

## 4. 完成定义

- 后端 Ruff、端到端测试和 Alembic 空库升级通过。
- 前端 ESLint、Vitest、Prettier 和生产构建通过。
- 桌面与移动视口中四个工作区均可访问，文字、控制器和画布无重叠。
- 粒子画布产生非空像素并支持拖拽、缩放、暂停、映射与点选。
- 仓库搜索不再发现旧业务模块、旧路由、旧环境变量或失效脚本。
